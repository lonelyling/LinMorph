# Model card template

Complete one card per hosted model; this is not a published card.

- Model name, release revision, authors and contact
- Public paper URL/citation and verified license
- Base model and required original assets
- Artifact type: mapper / initialization bank / recovered DiT / full resume
- Converted blocks and matching inference config
- Training microstep and optimizer updates
- Full-file SHA-256 and file size
- Installation and generation command
- Dataset provenance and permitted uses
- Benchmark protocol, scores and generation-variant qualifications
- Validation hardware, compute needs and limitations
